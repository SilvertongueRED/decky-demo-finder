Shows exactly why a Steam API key or wishlist load fails, instead of a generic message. One zip for Steam Deck (Decky Loader) and Windows.

## New
- **Key check on save.** After Grab Key from Steam Page, Paste Key from Clipboard or Save API Key, the plugin asks Steam whether it accepts the key. The toast shows the last 4 characters of the saved key and says "Steam accepted the key." or why not (for example "Steam rejected the key (HTTP 403)" or a network error).
- **Real reason on wishlist failure.** "Failed to load wishlist" now includes Steam's actual reply in brackets, such as the HTTP status, a network or certificate error, or "0 wishlist items returned".

## Install
Download `decky-demo-finder-v1.3.4.zip`, extract it into your Decky `plugins` folder (so you have `plugins/decky-demo-finder/`), then reload Decky / restart Decky Loader. The same zip works on Steam Deck and Windows.
