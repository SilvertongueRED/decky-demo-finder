Adds a controller shortcut for changing the sort method.

## New
- **Y button (Triangle on PlayStation controllers) cycles the sort method** in the full wishlist view: A → Z → Date Added → Release Date.
- A small hint next to "Current Sort Method" shows which button to press (also shown in the Steam footer legend as "Change Sort"). The label switches to Triangle when a PlayStation controller is detected.

## Unchanged from v1.1.0
- Card highlight on controller focus and mouse hover, L1 / R1 (LB / RB) page navigation, **A** = demo / store page, **X** = store page.

## Install
Download `decky-demo-finder-v1.2.0.zip`, extract it into your Decky `plugins` folder (so you have `plugins/decky-demo-finder/`), then reload Decky / restart Decky Loader.
