Improves opening the API key page on Windows. Includes the v1.3.5 Steam Deck certificate fix. One zip for Steam Deck (Decky Loader) and Windows.

## Fixed
- **Windows:** the plugin now asks its backend which operating system it runs on instead of guessing from the browser user agent, so **Get Your Free API Key** uses the default-browser opener on Windows. The backend also gains extra fallbacks for opening links on Windows (`webbrowser`, then `cmd start`).
- **Steam Deck:** includes the v1.3.5 fix for `unable to get local issuer certificate` (certificate verification now uses the system CA bundle).

## Install
Download `decky-demo-finder-v1.3.6.zip`, extract it into your Decky `plugins` folder (so you have `plugins/decky-demo-finder/`), then reload Decky / restart Decky Loader. The same zip works on Steam Deck and Windows.
