Get your Steam API key into Demo Finder without copying or pasting anything. Built for controller use on Steam Deck, docked or handheld. One zip for Steam Deck (Decky Loader) and Windows.

## New
- **Grab Key from Steam Page** button in the Steam API Key Setup section. Press **Get Your Free API Key**, register or view your key so it is on screen, come back to Demo Finder and press **Grab Key from Steam Page**. The plugin reads the key off the open Steam page through Steam's local debugger and saves it for you. No long-press, no copy, no paste.
- If no key page is open, a toast tells you what to do.

## Changed
- **Paste Key from Clipboard** stays as a backup. Steam's UI blocks programmatic clipboard reads on some setups, and the failure message now points you to the new button (or to long-press the key field and tap Paste).

## Notes
- Works on Steam Deck, where the key page opens inside Steam. On Windows the key page opens in your normal browser, so use Paste Key from Clipboard there.
- The plugin log (`~/homebrew/logs/`) lists the open Steam pages it saw if no key is found, lines starting with `grab_key`.

## Install
Download `decky-demo-finder-v1.3.3.zip`, extract it into your Decky `plugins` folder (so you have `plugins/decky-demo-finder/`), then reload Decky / restart Decky Loader. The same zip works on Steam Deck and Windows.
