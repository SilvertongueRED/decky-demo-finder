# Demo Finder v1.1.0

Fixes controller/mouse navigation in the full wishlist view.

## Fixed
- **Selection highlight is back.** The card you navigate to with the d-pad/stick, or hover/click with the mouse, now gets a clear blue outline + glow every time. Previously it only appeared occasionally because each card contained a hidden nested focus target that the controller kept landing on instead of the card.
- **L1 / R1 (LB / RB) page navigation works again.** Bumpers are now read from Steam's native gamepad events (the browser Gamepad API is kept as a fallback), and the focused card stays selected when the page changes.
- Header buttons (sort / filter / re-scan) and the Prev / Next buttons also highlight when focused or hovered.

## Changed
- **A** on a card plays the demo if it has one, otherwise opens the store page. **X** always opens the store page (shown in the Steam footer legend).
- Mouse: click a card for the same action as **A**; a small store-page button on each card opens the store page.
- `dist/index.js` is rebuilt from source, so it now matches `src/index.tsx`.

## Install
Download `decky-demo-finder-v1.1.0.zip`, extract it into your Decky `plugins` folder (so you have `plugins/decky-demo-finder/`), then reload Decky / restart Decky Loader.
