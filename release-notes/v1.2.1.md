Fixes cut-off Play Demo buttons and release dates on the full wishlist cards.

## Fixed
- Release dates no longer wrap onto a second line (e.g. "To be announced", "Jan 19, 2023"), which was pushing the **Play Demo** badge out of view on many cards.
- "To Be Announced" is now shown as **TBA** so it always fits (hover/title still shows the full text).
- Date, Play Demo badge and store-page button now share the card's bottom row evenly instead of using percentage margins, so spacing is consistent on every card.

## Install
Download `decky-demo-finder-v1.2.1.zip`, extract it into your Decky `plugins` folder (so you have `plugins/decky-demo-finder/`), then reload Decky / restart Decky Loader.
