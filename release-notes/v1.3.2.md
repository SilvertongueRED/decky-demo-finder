Makes entering your Steam API key easy with a controller or touch screen. One zip for Steam Deck (Decky Loader) and Windows.

## New
- **Paste Key from Clipboard** button in the Steam API Key Setup section. Copy your key on the Steam page, come back to Demo Finder, press the button, then press **Save API Key**. No Steam virtual keyboard paste needed.
- The key is found automatically: if you copy more than just the key (for example long-press, Select All, Copy on the Steam page), the 32 character key is picked out of the copied text.
- If nothing usable is on the clipboard, a toast tells you what to copy.

## How it reads the clipboard
Tries the browser clipboard first, then a hidden paste field, then the plugin backend (xclip, wl-paste or xsel on Linux, PowerShell on Windows).

## Install
Download `decky-demo-finder-v1.3.2.zip`, extract it into your Decky `plugins` folder (so you have `plugins/decky-demo-finder/`), then reload Decky / restart Decky Loader. The same zip works on Steam Deck and Windows.
