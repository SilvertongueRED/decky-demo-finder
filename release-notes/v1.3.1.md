Fixes the "Get Your Free API Key" button on Steam Deck. One zip for Steam Deck (Decky Loader) and Windows.

## Fixed
- **Steam Deck:** tapping **Get Your Free API Key** only closed the Quick Access menu and never opened the Steam API key page. The Linux `xdg-open` call reported success but showed no window in Game Mode. On Deck/Linux the button now opens the page in Steam's built-in browser first (falling back to the system browser, then `xdg-open`).
- **Windows:** unchanged. The button still opens your default browser.
- If every method fails, a toast now shows the link instead of failing silently.

## Install
Download `decky-demo-finder-v1.3.1.zip`, extract it into your Decky `plugins` folder (so you have `plugins/decky-demo-finder/`), then reload Decky / restart Decky Loader. The same zip works on Steam Deck and Windows.
