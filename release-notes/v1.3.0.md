One zip for Steam Deck (Decky Loader) and Windows, with button prompts that match the controller you're using.

## New
- **Controller-aware button prompts.** The page buttons and the sort hint now show the right glyphs for your controller:
  - Xbox / Steam Controller / Steam Deck: **LB / RB**, sort = **Y**
  - PlayStation: **L1 / R1**, sort = **Triangle**
  - Nintendo Switch: **L / R**, sort = **X**
- The active controller is detected automatically (it follows whichever pad you used last), and the prompts update when you switch.
- New **Button Icons** button in the Quick Access menu (Options) cycles Auto / Xbox / PlayStation / Switch. Use it if Steam Input shows your pad as a generic Xbox controller. The choice is remembered.

## Fixed
- **Windows:** "Get Your Free API Key" and other external links no longer rely on `xdg-open` (Linux-only). Windows uses the default browser, macOS uses `open`, Linux keeps `xdg-open`.
- Cache and settings files are now read and written as UTF-8 explicitly, so non-English game names survive on Windows.

## Install
Download `decky-demo-finder-v1.3.0.zip`, extract it into your Decky `plugins` folder (so you have `plugins/decky-demo-finder/`), then reload Decky / restart Decky Loader. The same zip works on Steam Deck and Windows.
