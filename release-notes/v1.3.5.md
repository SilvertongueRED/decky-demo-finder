Fixes "Failed to load wishlist (ClientConnectorCertificateError ... unable to get local issuer certificate)" on Steam Deck. One zip for Steam Deck (Decky Loader) and Windows.

## Fixed
- **Steam Deck:** Decky's bundled Python could not find any trusted certificates, so every HTTPS request to Steam failed certificate verification, including the wishlist, app details and the new key check. The plugin now loads the system CA bundle (for example `/etc/ssl/certs/ca-certificates.crt`) itself. Certificate verification stays on.
- The plugin log (`~/homebrew/logs/`) now says which CA bundle was used ("Using CA bundle: ...").

## Install
Download `decky-demo-finder-v1.3.5.zip`, extract it into your Decky `plugins` folder (so you have `plugins/decky-demo-finder/`), then reload Decky / restart Decky Loader. The same zip works on Steam Deck and Windows.
